## 📋 Description

Create web interface for Community Managers to view and manage invitations with React frontend and ElizaOS HTTP routes.

**Key Goals**:
- Build `/api/invitations` REST endpoints
- Create React invitation management page
- Display invitation cards with status
- Implement copy-to-clipboard functionality
- Add role-based access control

## 📝 Implementation Notes

### API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/invitations` | List invitations (query: userId, status) |
| POST | `/api/invitations` | Create invitation (body: userId, invitedUsername?, expiresInDays?) |
| GET | `/api/invitations/:id` | Get single invitation |
| DELETE | `/api/invitations/:id` | Cancel invitation |
| GET | `/api/invitations/stats` | Get invitation statistics (query: userId) |

### Frontend Components

**InvitationCard**:
- Status badges with color coding (pending: yellow, accepted: green, expired: gray, cancelled: red)
- Copy code button with clipboard API
- Cancel button with confirmation dialog
- "Expiring soon" indicator for invitations expiring within 24 hours

**Invitations Page**:
- Stats cards showing counts by status
- Status filter buttons
- TanStack Query for data fetching with automatic refetch
- Toast notifications for success/error feedback
- Loading and error states
