## 📋 Description

Implement an ElizaOS Action for Community Managers to create and manage member invitations through natural conversation with the agent.

**Key Insight**: The Telegram integration already exists via `@elizaos/plugin-telegram`. Instead of slash commands, users interact conversationally with the agent (kukulcán), which is more natural and platform-agnostic.

**Example Interactions**:
- "I need an invite code for my friend"
- "Create an invitation"
- "Show me my pending invitations"
- "Cancel invitation ABC123"

**Key Goals**:
- Create conversational invitation action
- Implement role-based access control
- Generate invitation codes via InvitationService
- Display shareable invitation information
- Platform-agnostic (works on Telegram, Discord, etc.)

## 📐 Technical Approach

### Data Access Strategy
- **ElizaOS Memory**: Conversation history during invitation creation
- **Drizzle/PostgreSQL**: Invitation creation via InvitationService

### Architecture Notes
**Action Pattern** (from ARCHITECTURE_RECOMMENDATION.md):
- Extends ElizaOS Action interface
- `validate()` checks for invitation-related intent + Community Manager role
- `handler()` creates invitation via InvitationService and responds
- Platform-agnostic - no Telegram-specific code

**Role Validation**: Deferred to post-MVP. Any user can create invitations.

**Intent Recognition**:
- Handled by LLM via action's `name`, `similes`, and `description`
- `validate()` is for precondition checks only (not intent detection)

## 📝 Implementation Notes

### Action Implementation

```typescript
// actions/inviteAction.ts
import type { Action, IAgentRuntime, Memory, State, HandlerCallback } from '@elizaos/core';
import { InvitationService } from '../services/InvitationService';

export const inviteAction: Action = {
  name: 'CREATE_INVITATION',
  similes: ['GENERATE_INVITE', 'MAKE_INVITATION', 'NEW_INVITE'],
  description: 'Creates a community invitation code for the user',

  validate: async (runtime: IAgentRuntime, message: Memory, state?: State): Promise<boolean> => {
    const text = message.content?.text?.toLowerCase() || '';

    // Check for invitation-related intent
    const hasInviteIntent =
      text.includes('invite') ||
      text.includes('invitation') ||
      text.includes('join code');

    if (!hasInviteIntent) return false;

    // TODO: Role check - verify user is community_manager
    // For MVP, allow all users (role check added in CD-201)
    return true;
  },

  handler: async (
    runtime: IAgentRuntime,
    message: Memory,
    state?: State,
    options?: Record<string, unknown>,
    callback?: HandlerCallback
  ) => {
    try {
      const invitationService = runtime.getService('invitation-service') as InvitationService;

      // Create invitation
      const invitation = await invitationService.createInvitation({
        inviterId: message.entityId,
        inviterName: message.metadata?.entityUserName as string || 'Unknown',
        maxUses: 1,
      });

      // Format response with kukulcán personality
      const responseText = `
🐍 *Invitation Created*

Your sacred code: \`${invitation.code}\`
Expires: ${invitation.expiresAt.toLocaleDateString()}

Share this code with those worthy of joining our community. They can use it to register and become part of the Frutero collective.
      `.trim();

      if (callback) {
        await callback({ text: responseText, action: 'CREATE_INVITATION' });
      }

      return {
        success: true,
        text: responseText,
        data: {
          invitationId: invitation.id,
          code: invitation.code,
          expiresAt: invitation.expiresAt,
        },
      };
    } catch (error) {
      const errorText = 'I encountered an issue creating your invitation. Please try again.';

      if (callback) {
        await callback({ text: errorText });
      }

      return {
        success: false,
        text: errorText,
        error: error instanceof Error ? error : new Error(String(error)),
      };
    }
  },

  examples: [
    [
      {
        user: '{{user1}}',
        content: { text: 'I need an invite code for my friend' },
      },
      {
        user: '{{agent}}',
        content: {
          text: '🐍 *Invitation Created*\n\nYour sacred code: `ABC123XYZ789`\nExpires: 12/10/2024\n\nShare this code with those worthy of joining our community.',
          action: 'CREATE_INVITATION',
        },
      },
    ],
    [
      {
        user: '{{user1}}',
        content: { text: 'Can you create an invitation?' },
      },
      {
        user: '{{agent}}',
        content: {
          text: '🐍 *Invitation Created*\n\nYour sacred code: `DEF456GHI012`\nExpires: 12/10/2024\n\nShare this code with those worthy of joining our community.',
          action: 'CREATE_INVITATION',
        },
      },
    ],
  ],
};

export default inviteAction;
```
