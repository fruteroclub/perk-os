## 📋 Description

Create service to verify GitHub profiles and collect activity data using GitHub API.

**Key Goals**:
- Verify GitHub username exists
- Collect profile data (repos, followers, stars, contributions)
- Store raw profile data in JSONB field
- Handle GitHub API rate limiting
- Cache responses for performance

---

- [ ] Collects: public_repos, followers, total_stars, contributions
- [ ] Stores raw profile data in JSONB field
- [ ] Handles rate limiting gracefully (retry, backoff)
