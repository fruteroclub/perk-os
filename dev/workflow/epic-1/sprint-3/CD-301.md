## 📋 Description

Build DirectoryService with complex filtering, search, and pagination for member queries.

**Key Goals**:
- Complex filtering by role, country, reputation
- Full-text search on name and organization
- Pagination with configurable page size
- Sort by reputation, join date, activity
- Performance optimization with indexes
